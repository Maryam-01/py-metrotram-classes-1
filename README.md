## The Brief

Dom has raised a new ticket. Metro Tram's reliability data is in good shape now thanks to the pipeline work, but the operations side of the business is still entirely run on spreadsheets. Priya has signed off on a project to start modernising fleet and staff management. Specifically, she wants a proper system for tracking which trams are in service, which need maintenance, which drivers are qualified for which routes, and who is on shift.

Dom has left a note in the ticket:

> _"This is a greenfields project. Take time to think about what the objects actually are before you start writing classes. Suki has put together some sample data to work from. Tests are non-negotiable, fixtures expected, and I want to see your design decisions written down somewhere I can read them."_

Suki has dropped a `data/` folder into the repo with sample fleet and staff data in JSON and CSV formats. The data is clean enough to work with but reflects real operational concerns. You will use it to drive your tests and to surface validation requirements as you go.
